## Existing path corrections

- Chat application now executes a stream crash and bounded recovery; acknowledged
  chunks and durable message identity survive without duplicate effects.
- Social feed now executes fanout retry exhaustion and dead-letter quarantine;
  queue acceptance is explicitly distinct from timeline delivery.
- RAG prose describes synthetic count/publication/service-time behavior rather
  than claiming semantic retrieval or cross-encoder quality measurements.
- Video prose removes unsupported regional locality and offload percentages.

Evolution stages and detail levels are separate axes, documented in
[system-diagram.md](system-diagram.md). Walkthrough steps remain architectural
experiments at the current simulation stage. Synthetic service times, finite
traces and in-memory state do not establish production capacity, real durability,
SMTP/WebSocket delivery, provisioning or cloud deployment capabilities. The
implementation/deployment compiler support set was not expanded.

## Follow-up shared-kernel and lifecycle review

The repeat/interruption review added regressions and corrected three API cases:
repeated mutation preserves unique sorted keys; an old charge acknowledgement
cannot undo a same-version cancellation; crash clears orphan pending calls while
retaining committed lifecycle identity. Event-ledger lookup uses own keys so
prototype member names cannot masquerade as committed events. The focused run
passes 76/76 tests after those fixes. Each new stage still passes coordinator
verification and checkpoint continuation.
