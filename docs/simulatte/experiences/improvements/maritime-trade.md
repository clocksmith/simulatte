## Frontier improvements

The initial frontier direction is a global operations story in which vessels,
cargo, port capacity, queues, schedules, chokepoints, weather, fuel, and
emissions interact over time. Users should reroute traffic or change operating
policy during disruption, then see delayed cargo, port congestion, cost, and
emissions propagate across the network with inspectable causes.

## Acceptance gates

- [ ] Vessels and cargo retain identity, quantity, route, and schedule state.
- [ ] Port queues respect ordering and handling capacity.
- [ ] Interventions visibly propagate beyond the selected vessel or port.
- [ ] The deep frontier review defines hierarchy and decision tension.
- [ ] Current desktop and mobile browser reviews prove global readability.
