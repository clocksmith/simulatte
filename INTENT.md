# INTENT: simulatte

Parent: none

## Need

Creators need focused browser simulation products that share reliable execution machinery without merging interfaces, domain policy, or evidence claims.

## Target

Keep World and Blank/Create independently useful, with a small browser-native core for explicit contracts, bounded execution, cancellation, and replay.

## Invariants

Preserve the hexagon entrypoint and optional data tools. Shared code owns no page lifecycle. Use documented core entrypoints and injected adapters. Prompt compilation follows exactly eight phases and declared predecessor inputs. Preserve user edits through the append-only authoring graph. Supported free local execution needs no account, network, or model download.

## Evidence

Use charter and folder-contract checks, deterministic execution tests, installed-core consumption, and actual pixel-obligation evidence for their separate boundaries. Receipts alone do not prove scientific validity or correct rendering. Retain failed obligations and qualified determinism limits.

## Non-goals

No universal shell, fabricated scene dynamics, fixture substitution for general compilation, or unverified solver claims.

[GOVERNANCE_DETAILS.md](GOVERNANCE_DETAILS.md) preserves detailed requirements and evidence commands. Identified WorldSpec artifacts, execution records, replay results, and pixel settlement govern claims. Source structure and syntax checks cannot substitute for browser evidence.
